# T计划桌宠 · 角色资源包接口说明（格式版本 1）

> 本文件可以直接交给美术设计助手。
> 程序只负责**加载和显示**你提供的图片，不会绘制、修改或替代角色。
> 当前程序版本支持的能力以「§6 当前支持范围」为准，没有列出的不要假设已经支持。

---

## 1. 最少需要什么

**一张透明背景的 PNG 立绘（idle）+ 一个 manifest.json，就能让桌宠完整运行。**

拖拽、透明区域穿透、计时、提醒、记录等功能都不依赖更多素材。其他状态的图片可以以后逐步补充；缺少的状态会自动显示 idle。

---

## 2. 目录结构示例

```
T计划学者少女/                 ← 资源包文件夹（名字随意）
├─ manifest.json              ← 必需，UTF-8 编码
└─ states/
   ├─ idle.png                ← 必需：默认待机
   ├─ focus.png               ← 可选：专注陪读
   ├─ thinking.png            ← 可选：查看任务 / 思考
   ├─ reminder.png            ← 可选：轻提醒
   ├─ timeUp.png              ← 可选：计时结束
   ├─ done.png                ← 可选：完成一个步骤
   ├─ rest.png                ← 可选：休息
   └─ dragging.png            ← 可选：被拖拽
```

文件夹和文件名建议只用英文小写字母、数字、`-`、`_`。文件名不要带 `@2x` 一类后缀，程序按图片的真实像素尺寸读取。

---

## 3. manifest.json 完整示例

```json
{
  "format": "tplan-character-pack",
  "formatVersion": 1,
  "id": "tplan-scholar",
  "name": "T计划 · 学者少女",
  "version": "1.0.0",
  "author": "（作者或来源）",

  "canvas": { "width": 1200, "height": 1600 },
  "anchor": { "x": 600, "footY": 1560 },

  "display": {
    "defaultHeight": 260,
    "figureTop": 70
  },

  "hit": {
    "alphaThreshold": 40,
    "dilatePx": 8
  },

  "states": {
    "idle":     { "type": "static", "src": "states/idle.png" },
    "focus":    { "type": "static", "src": "states/focus.png" },
    "thinking": { "type": "static", "src": "states/thinking.png" },
    "reminder": { "type": "static", "src": "states/reminder.png" },
    "timeUp":   { "type": "static", "src": "states/timeUp.png" },
    "done":     { "type": "static", "src": "states/done.png" },
    "rest":     { "type": "static", "src": "states/rest.png" },
    "dragging": { "type": "static", "src": "states/dragging.png" }
  }
}
```

只有 idle 时，`states` 写成这样即可：

```json
"states": { "idle": "states/idle.png" }
```

（字符串写法等同于 `{ "type": "static", "src": "..." }`。）

---

## 4. 字段说明

| 字段 | 必需 | 说明 |
|---|---|---|
| `format` | 是 | 固定为 `"tplan-character-pack"` |
| `formatVersion` | 是 | 整数，当前为 `1`。如果高于程序支持的版本，程序会拒绝加载并提示更新 |
| `id` | 是 | 资源包标识：小写字母、数字、`.`、`_`、`-`，不超过 64 字符 |
| `name` | 是 | 显示名称，可以用中文 |
| `version` | 是 | 资源包自身的版本号，例如 `"1.0.0"`；每次更新美术时建议递增 |
| `author` | 否 | 作者或来源说明 |
| `canvas.width` / `canvas.height` | 是 | 画布像素尺寸。**所有状态图片必须与它完全一致** |
| `anchor.x` | 是 | 人物水平定位点（画布像素）：一般取两脚中间 |
| `anchor.footY` | 是 | 脚底基准线（画布像素）：鞋底最低处所在的 y 坐标。程序把这条线固定在屏幕上，切换状态和改变大小时人物不会上下跳动 |
| `display.defaultHeight` | 否 | 默认显示高度，单位为屏幕 DIP（Windows 缩放前的像素），范围 120–600，默认 260。指从 `figureTop` 到 `footY` 的人物高度。用户可以在托盘中调整 |
| `display.figureTop` | 否 | 人物顶部的 y 坐标（画布像素），用来计算“人物高度”。不填时，程序取 idle 图中最高的可见像素（含呆毛、发饰）。如果希望呆毛不计入高度，就手动填写头顶位置 |
| `hit.alphaThreshold` | 否 | 1–254，默认 40。透明度高于此值的像素可以点击和拖拽；低于或等于此值的像素会让鼠标穿透到后面的窗口 |
| `hit.dilatePx` | 否 | 0–64 画布像素，默认 8。把可点击范围向外扩一点，方便抓住细发丝 |
| `states.<状态名>` | idle 必需 | 见 §5。`src` 是资源包内的相对路径，不能是绝对路径，也不能包含 `..` |

## 5. 状态名称、触发条件与回退规则

状态由**真实的学习事件**决定，与图片无关。更换或缺少图片不会改变计时和记录。

| 状态名 | 含义 | 何时进入 | 何时离开 |
|---|---|---|---|
| `idle` | 默认待机 | 没有其他状态成立时 | — |
| `focus` | 专注陪读 | 计时正在进行（从桌宠或主窗口开始都算） | 暂停、结束、时间到 |
| `dragging` | 被拖拽 | 按住角色并移动超过 4 像素 | 松手，回到当时应有的状态 |
| `thinking` | 查看任务 / 思考 | 没有计时在进行时，打开需要查看或选择的气泡：任务卡片、换一件、缩小一步、结束后的“这一步怎么样” | 关闭卡片 |
| `reminder` | 轻提醒 | 出现需要回应的提醒：休眠、退出或意外中断后计时被自动暂停；休息结束 | 处理或关闭提醒 |
| `timeUp` | 计时结束 | 倒计时到 0 | 选择继续、结束或休息 |
| `done` | 完成一个步骤 | 把任务标记为完成（桌宠或主窗口） | 约 2.5 秒后自动结束 |
| `rest` | 休息 | 休息倒计时进行中 | 休息结束 |

**同时满足多个条件时的优先级**（从高到低）：

`dragging` > `done` > `timeUp` > `reminder` > `rest` > `focus` > `thinking` > `idle`

例如：专注计时中被拖动，显示 `dragging`；松手后自动回到 `focus`。暂停中的计时显示 `idle`。

**素材回退规则：**

1. 某个状态在 manifest 中没有写，或者它的图片找不到、无法解码、尺寸与画布不一致 → 该状态**显示 idle 图片**，业务功能照常运行，并在「T计划 → 角色资源」里列出提示。
2. 使用了当前版本尚未支持的类型（如 `sequence`、`layered`）→ 同样显示 idle，并给出提示。
3. **idle 本身不可用** → 整个资源包加载失败：
   - 如果之前已经加载过一个可用的资源包，就**继续使用之前的资源包**，同时提示错误原因；
   - 如果没有可用的资源包，桌宠显示一张“未加载角色素材”提示卡片。卡片可以拖动，计时和任务功能照常可用。程序**不会**画一个人物来替代。
4. 任何资源包错误都不会修改 T计划 的任务和记录，也不会打断正在进行的计时。

## 6. 当前支持范围（实话）

| 能力 | 状态 |
|---|---|
| 每个状态一张静态透明 PNG（`type: "static"`） | ✅ 已实现，已自动化验证 |
| 缺少状态时回退到 idle | ✅ 已实现，已自动化验证 |
| 根据当前显示图片的透明度生成点击范围 | ✅ 已实现，已自动化验证 |
| 改变显示大小后点击范围同步更新 | ✅ 已实现，已自动化验证 |
| 可选 blink PNG、idle 眨眼、整体轻微呼吸 | ✅ 已实现，支持减少动作；不是分层动画 |
| 序列帧动画（`type: "sequence"`） | ⏳ 仅保留字段名，**未实现**，会显示 idle |
| 分层动画（眨眼、呼吸等，`type: "layered"`） | ⏳ 仅保留字段名，**未实现**，会显示 idle |
| WebP、JPEG、GIF、APNG、PSD | ❌ 不支持，只接受 PNG |

序列帧和分层动画的字段格式会在实现时再确定，不要提前按某种格式制作大量动画素材。

## 7. 美术制作与导出要求

### 7.1 画布与定位

- **所有状态使用同一张画布尺寸**，人物脚底放在同一条线上（`anchor.footY`），两脚中间放在同一个 x 位置（`anchor.x`）。这样切换状态时人物不会跳动或左右偏移。
- 推荐画布：宽 1200 × 高 1600 像素。人物从头顶到鞋底大约 1300–1500 像素高。
  - 人物高度至少 1000 像素，桌宠放大或在高缩放屏幕上才能保持清晰。
- 四周留出至少 20 像素的透明边距，**不要让头发、花饰、飘带或鞋子碰到画布边缘**。
- 动作较大的状态（例如抬手），也要在同一画布内画完，不能超出画布。
- 脚底下方可以留少量透明空间，但 `anchor.footY` 必须对准鞋底。程序会检查每张图片最低的可见像素，如果与 footY 相差超过画布高度的 3%，会给出提示。

### 7.2 透明度

- 格式为 PNG，32 位 RGBA，**真实的透明背景**。
  - 不要白底、黑底或棋盘格底。
  - 画布四角应完全透明。校验允许 alpha ≤ 2/255 的量化残留；超过时提示“看起来没有透明背景”。
- 衣服、皮肤、头发等实体部分是**完全不透明**（alpha = 255）。奶油白衣服不要做成半透明。
- 只有边缘抗锯齿允许半透明（建议不超过 2 像素宽），以及确实需要的发梢、轻纱。
- **不要带白边、黑边或外发光。** 导出前请分别放在纯白、深色（如 `#1F1E1D`）和花哨的壁纸上检查边缘。
- 不要在图片里画阴影、地面、光晕、气泡、文字或 UI。气泡和计时小条由程序另外显示。

### 7.3 颜色与尺寸

- 颜色空间为 sRGB，不要嵌入特殊色彩配置。程序不会调整颜色、亮度或透明度。
- 程序只做**等比例缩放**，不拉伸、不裁剪、不加滤镜、不加描边。
- 桌宠默认显示约 260 DIP 高，所以过细的刺绣、链条和挂饰缩小后会糊成一团。
  - 请用 260 像素和 200 像素的缩小图检查：脸、眼睛方向、花饰和书本标记是否仍能看清。
- 单张图片建议小于 4 MB。

### 7.4 点击范围（命中区域）

- 你不需要提供单独的点击遮罩。程序会根据**当前显示的那张图片**的透明度自动生成点击范围。
- 透明度 ≤ `alphaThreshold`（默认 40/255，约 16%）的像素：鼠标穿透到后面的窗口。
- 其余像素可以单击、右键和拖拽。可点击范围会向外扩 `dilatePx`（默认 8 画布像素）：
  - 在 260 显示高度下，相当于向外多出约 1–2 个屏幕像素，方便抓住细发丝；
  - 代价是紧贴人物边缘 1–2 像素以内的点击会落在桌宠上，而不是后面的窗口。
- 如果某些很淡的半透明装饰（例如轻纱）不希望被点到，可以提高 `alphaThreshold`。

### 7.5 命名与交付

- 每个状态一张：`states/<状态名>.png`，状态名大小写与 §5 一致（例如 `timeUp.png`）。
- 交付内容：资源包文件夹（含 manifest.json 和 PNG），以及一份简短说明：
  - 画布尺寸；
  - footY 和 anchor.x 的取值依据；
  - 每张图对应的状态。
- 更新美术时，**修改 `version`**，并尽量保持画布尺寸和锚点不变；如果改变了，同步修改 manifest。

## 8. 交付前自查清单

- [ ] `manifest.json` 是有效的 JSON，`format` / `formatVersion` / `id` / `name` / `version` 都已填写
- [ ] 有 `states.idle`，图片存在
- [ ] 所有 PNG 的像素尺寸都等于 `canvas`
- [ ] 四角完全透明；衣服和皮肤不透明；边缘没有白边或黑边
- [ ] 每张图的鞋底都落在 `anchor.footY`；两脚中间在 `anchor.x`
- [ ] 头发、花饰、飘带、鞋子都没有碰到画布边缘
- [ ] 缩小到 200 和 260 像素高时，表情和主要特征仍能辨认
- [ ] 图里没有阴影、地面、背景、文字或气泡
